The problem

Web tools can't turn agentic traffic into revenue.

<1%

of online tools can charge agents for their work and IP, so they just block agent traffic.

To get paid by an agent today, a creator needs an engineering team:

  1. 1Offer an API
  2. 2Create an MCP server
  3. 3Add billing
The solution

AgentPass turns HTTP 402 into Stripe Checkout for agents.

A ready-to-install library. One sentence in Claude Code. Under the hood: one gate, one payment, one pass.

1

Request access

The agent asks for a resource and gets HTTP 402 with the price.

402 · 0.05 USDC
2

Pay the creator

The agent pays USDC via MPP on Stellar, with its own key.

MPP · Stellar
3

Issue pass

A Soroban contract records the pass and its expiry.

agent_pass.issue
4

Return result

The app returns the content and a signed access pass.

200 · Agent-Pass
